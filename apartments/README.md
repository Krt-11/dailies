# Polaris Apartment Shortlist

Interactive apartment map for the Polaris area.

## Files

- `index.html` — page structure/content
- `style.css` — visual styling
- `app.js` — map, apartment data, filters, and interactions

## GitHub Pages

Put this entire folder in your repository, for example:

```text
Projects/
└── apartments/
    ├── index.html
    ├── style.css
    └── app.js
```

Then configure the repository's Pages source to use GitHub Actions or a branch, depending on how the repository is organized.
